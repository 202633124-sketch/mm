# 🚇 부산 지하철 역별 이용객 수 지도 분석 앱

Streamlit과 Folium을 활용하여 부산 지하철 역별 이용객 수를 웹 지도상에 시각화하고 분석할 수 있는 파이썬 애플리케이션입니다.

---

## 📌 주요 기능
1. **CSV 데이터 업로드 및 조회**: 사용자 지정 CSV 데이터를 업로드하고 전체 테이블을 확인합니다.
2. **호선별 필터링**: `multiselect`를 통해 조회하고 싶은 호선(1~4호선)을 다중 선택하여 지도를 필터링합니다.
3. **이용객 상위 5개 역 표시**: 필터링된 데이터 중 이용객 수가 가장 많은 상위 5개 역을 정렬하여 보여줍니다.
4. **지도 시각화 (Folium Map)**:
   - 역 위치에 `CircleMarker`를 생성합니다.
   - 이용객 수의 제곱근($\sqrt{\text{이용객수}}$)에 비례하여 원의 반지름 크기를 조정합니다.
   - 호선별로 구분된 마커 색상을 적용합니다. (1호선: 주황, 2호선: 초록, 3호선: 갈색, 4호선: 파랑)
   - **Tooltip**: 마우스를 오버하면 `[호선] 역명`을 표시합니다.
   - **Popup**: 클릭 시 역명, 호선 및 세부 이용객 수를 팝업창으로 출력합니다.

## 📂 파일 구조
```text
.
├── app.py                # Streamlit 메인 실행 파일
├── busan_subway.csv      # 부산 지하철 역별 데이터셋 (열: 호선, 역명, 위도, 경도, 이용객수)
├── requirements.txt      # 필요 라이브러리 목록
└── README.md             # 프로젝트 설명 문서
```

---

## 🛠️ 필수 라이브러리 설치
프로젝트 실행 전 터미널(CMD)에서 아래 명령어를 실행하여 필요한 패키지를 설치합니다.

```bash
pip install -r requirements.txt
```

---

## 🚀 실행 방법
터미널에서 아래 명령어를 입력하여 Streamlit 서버를 구동합니다.

```bash
streamlit run app.py
```
